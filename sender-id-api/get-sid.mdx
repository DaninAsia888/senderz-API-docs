---
title: "Get Sender ID status"
api: "GET /v1/sids/{sid_id}"
description: "Retrieve the current status and details of a Sender ID registration."
---

**Required permission:** `sids:read`

## Path parameters

<ParamField path="sid_id" type="string" required>
  The SID ID (e.g. `sid_j1k2l3m4`).
</ParamField>

## Example

```bash
curl https://api.senderz.ai/v1/sids/sid_j1k2l3m4 \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxxx"
```
