---
title: "List Sender IDs"
api: "GET /v1/sids"
description: "List Sender ID registrations with optional filters."
---

**Required permission:** `sids:read`

## Query parameters

<ParamField query="market" type="string">
  Filter by ISO 3166-1 alpha-2 country code.
</ParamField>

<ParamField query="status" type="string">
  Filter by SID status: `pending_review`, `pending_register`, `pending_owner_confirmation`, `registered`, `rejected`, `suspended`, `deregistered`.
</ParamField>

<ParamField query="brand_id" type="string">
  Filter by brand entity.
</ParamField>

<ParamField query="sender_id" type="string">
  Filter by Sender ID string (partial match).
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor.
</ParamField>

<ParamField query="page_size" type="integer" default="50">
  Results per page. Maximum 100.
</ParamField>

## Example

```bash
curl "https://api.senderz.ai/v1/sids?market=AU&status=registered&page_size=25" \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxxx"
```
