---
title: "Get authorisation"
description: "Retrieve a single associate authorisation by ID."
---

Retrieve one associate authorisation belonging to your account.

<api method="GET" url="https://api.senderz.ai/v1/associate-authorisations/{id}" />

**Required permission:** `authorisations:read`

## Path parameters

<ParamField path="id" type="string" required>
  The authorisation ID (e.g. `aa_a1b2c3`).
</ParamField>

## Response

<ResponseField name="id" type="string" />
<ResponseField name="state" type="string">
  `awaiting_owner_confirmation`, `awaiting_sid_verification`, `authorised`, `pending_authority`, `active`, or `declined`. `pending_authority` means the authorisation has been lodged with the country's registration authority and is awaiting its confirmation.
</ResponseField>
<ResponseField name="country" type="string" />
<ResponseField name="authority" type="string">
  The country's registration authority (`ACMA` for AU), or `null` where none is live.
</ResponseField>
<ResponseField name="claimed_sender_id" type="string" />
<ResponseField name="owner_entity_name" type="string" />
<ResponseField name="owner_entity_abn" type="string" />
<ResponseField name="owner_rep_name" type="string" />
<ResponseField name="owner_rep_email" type="string" />
<ResponseField name="owner_confirmed_sid_is_authority_verified" type="boolean">
  Whether the owner attested that the Sender ID is already verified under the market's scheme.
</ResponseField>
<ResponseField name="owner_confirmed_at" type="string" />
<ResponseField name="declined_at" type="string" />
<ResponseField name="decline_reason" type="string" />
<ResponseField name="pending_authority_at" type="string" />
<ResponseField name="active_at" type="string" />
<ResponseField name="authority_reference" type="string">
  The authority's reference for the association, once issued.
</ResponseField>
<ResponseField name="created_at" type="string" />
<ResponseField name="updated_at" type="string" />

## Example

<CodeGroup>

```bash cURL
curl "https://api.senderz.ai/v1/associate-authorisations/aa_a1b2c3" \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx"
```
