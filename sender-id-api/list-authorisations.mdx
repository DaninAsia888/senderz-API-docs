title: "List authorisations"
description: "List and filter your associate authorisation requests."
---

List the associate authorisations belonging to your account, newest first, with cursor pagination and optional filters.

<api method="GET" url="https://api.senderz.ai/v1/associate-authorisations" />

**Required permission:** `authorisations:read`

## Query parameters

<ParamField query="state" type="string">
  Filter by state: `awaiting_owner_confirmation`, `awaiting_sid_verification`, `authorised`, `pending_authority`, `active`, `declined`. Any other value returns `400`.
</ParamField>

<ParamField query="country" type="string">
  Filter by market (ISO 3166-1 alpha-2).
</ParamField>

<ParamField query="owner_entity_abn" type="string">
  Filter by the Brand Owner's registration number.
</ParamField>

<ParamField query="claimed_sender_id" type="string">
  Filter by Sender ID.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from a previous response's `pagination.next_cursor`.
</ParamField>

<ParamField query="page_size" type="integer">
  Page size (default 50, max 100).
</ParamField>

## Example

<CodeGroup>

```bash cURL
curl "https://api.senderz.ai/v1/associate-authorisations?state=pending_authority&country=AU" \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx"
```
