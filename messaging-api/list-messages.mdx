---
title: "List messages"
api: "GET /v1/messaging/messages"
description: "List messages with optional filters for market, status, sender ID, and date range."
---

**Required permission:** `messaging:read`

## Query parameters

<ParamField query="market" type="string">
  Filter by ISO 3166-1 alpha-2 country code.
</ParamField>

<ParamField query="status" type="string">
  Filter by message status: `queued`, `sent`, `delivered`, `undelivered`, `failed`, `scheduled`, `cancelled`.
</ParamField>

<ParamField query="sender_id" type="string">
  Filter by Sender ID.
</ParamField>

<ParamField query="reference" type="string">
  Filter by your internal reference.
</ParamField>

<ParamField query="from" type="string">
  Start date (ISO 8601). Inclusive.
</ParamField>

<ParamField query="to" type="string">
  End date (ISO 8601). Inclusive.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from a previous response.
</ParamField>

<ParamField query="page_size" type="integer" default="50">
  Results per page. Maximum 100.
</ParamField>

## Example

```bash
curl "https://api.senderz.ai/v1/messaging/messages?market=AU&status=delivered&from=2026-07-01&page_size=25" \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxxx"
```
