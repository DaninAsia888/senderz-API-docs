---
title: "List registrations"
api: "GET /v1/operator-registrations"
description: "List Sender ID registrations submitted for your network."
---

**Required permission:** `operator:read`

Returns registrations filtered to the operator's network. Results are sorted by submission date (newest first).

## Query parameters

<ParamField query="status" type="string">
  Filter by status: `pending_operator_review`, `approved`, `info_requested`, `resubmitted`, `rejected`.
</ParamField>

<ParamField query="market" type="string">
  Filter by ISO 3166-1 alpha-2 country code.
</ParamField>

<ParamField query="sender_id" type="string">
  Filter by Sender ID string (partial match).
</ParamField>

<ParamField query="brand_name" type="string">
  Filter by brand entity name (partial match).
</ParamField>

<ParamField query="submitted_by_type" type="string">
  Filter by submitter type: `brand`, `aggregator`, `cpaas`.
</ParamField>

<ParamField query="submitted_after" type="string">
  ISO 8601 date. Only return registrations submitted after this date.
</ParamField>

<ParamField query="submitted_before" type="string">
  ISO 8601 date. Only return registrations submitted before this date.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor.
</ParamField>

<ParamField query="page_size" type="integer" default="50">
  Results per page. Maximum 100.
</ParamField>

## Example

```bash
curl "https://api.senderz.ai/v1/operator-registrations?status=pending_operator_review&market=AU" \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxxx"
```
